# Задание 6


1. **Создан Rate Limiting-зона**`partner_limit`:
   * **rate=10r/m** → ограничивает партнера **10 запросами в минуту**.
   * **zone=partner\_limit:10m** → создает область памяти 10MB для хранения информации о лимитах.
2. **Применен лимит в `location /`**:
   * `limit_req zone=partner_limit burst=5 nodelay;`
   * **burst=5** → если партнер превышает лимит, ему разрешается до **5 дополнительных запросов** перед блокировкой.
   * **nodelay** → немедленно отвечает **429 Too Many Requests**, если лимит превышен.
3. **Ошибка 429 обрабатывается**:
   * При превышении лимита клиенту отдается **"Too Many Requests - Please slow down."**.


### **Преимущества решения**

* Снижает нагрузку на API – предотвращает перегрузку сервиса одним партнером.
* Гибкая настройка – можно изменять `rate`, `burst` и `nodelay` в зависимости от требований.
* Легко расширяемо – можно настроить разные лимиты для разных IP/партнеров.
